# ⚡ MobileTech Admin Dashboard

**MobileTech Admin Dashboard** is a modern, high-performance admin panel built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.  
It’s designed to help you manage your **mobile & electronics shop** efficiently — from products and inventory to orders, analytics, and customer insights.

---

## 🚀 Overview

MobileTech Admin provides everything you need to manage a growing tech store with ease.  
It includes complete tools, pages, and UI components for running a professional e-commerce management system.

### Core Features
- 📱 **Product & Category Management**
- 💰 **Order Tracking & Sales Analytics**
- 👤 **Customer Overview & User Management**
- 📊 **Data Visualization with Charts & Tables**
- 🧭 **Dashboard Overview Page**
- 🔒 **Authentication with JWT**
- 🌓 **Dark / Light Mode**
- ⚡ **Fast performance with SSR + SSG**

Built with the **Next.js 15 App Router**, **React Server Components**, and **TypeScript**, ensuring modern architecture, scalability, and smooth development.
